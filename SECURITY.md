# Security Policy

## Supported versions

This project is currently a pilot. Maintainers determine which deployments and revisions are actively supported. When reporting a vulnerability, include the affected version or commit, if known.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately using this repository's **Report a vulnerability** option on the **Security** tab, if available. Do not report vulnerabilities in public issues, discussions, or pull requests.

If private vulnerability reporting is unavailable, contact the repository maintainers through a private channel you already have access to. Do not include exploit details in a public message while requesting a contact method.

Please include enough information to help maintainers understand and reproduce the issue, such as the affected component, impact, and steps to reproduce. Avoid accessing, changing, or deleting data that is not yours while investigating.

The maintainers will review reports and coordinate any fixes and disclosure with the reporter. No response or resolution timeline is promised at this time.
